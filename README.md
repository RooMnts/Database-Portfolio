# Car Renting Database Project

## Project Overview

This repository contains an academic car rental database project developed as part of the Higher Diploma in Computing at CCT College Dublin.

The project focuses on designing and implementing a relational database using MySQL and integrating it with a Java console application to perform database searches.

## Database Design

The database was designed to manage information related to a car rental system. It includes the following tables:

* **Client:** Stores customer information.
* **CarCare:** Stores information related to car care.
* **ServiceInformation:** Contains service-related information.
* **CarHire:** Manages car hire records.
* **Reservation:** Stores reservation information.

The project includes database design diagrams to illustrate the database structure and the relationships between its entities.

## Technologies Used

* **MySQL:** Relational database creation, implementation, and querying.
* **SQL:** Data manipulation, filtering, aggregation, and relational queries.
* **Java:** Console application development and database integration.

## SQL Features

The SQL implementation demonstrates several database concepts and operations, including:

* Creating tables and defining primary and foreign keys.
* Applying data integrity constraints.
* Inserting and managing records.
* Filtering and sorting query results.
* Grouping data using `GROUP BY` and `HAVING`.
* Retrieving related data using `INNER JOIN`, `LEFT JOIN`, and `RIGHT JOIN`.
* Combining query results to simulate a `FULL OUTER JOIN`.
* Using aggregate functions such as `COUNT()` and `SUM()`.
* Performing data updates and deletions.

## Java Application

The Java component connects to the MySQL database and allows users to search for information through a console-based interface.

The project demonstrates the integration of Java with a relational database to retrieve information using SQL queries.
